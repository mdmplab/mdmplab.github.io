# MDMP Lab V30 · GitHub Pages 배포용

## 업로드
1. ZIP을 압축 해제합니다.
2. 기존 mdmplab/mdmplab.github.io 저장소 최상위의 index.html을 새 파일로 교체합니다.
3. .nojekyll도 저장소 최상위에 함께 올릴 수 있습니다. ZIP 자체가 아니라 압축 해제한 파일을 올려주세요.
4. Settings → Pages에서 Deploy from a branch, main, /(root)를 선택합니다.
5. 배포 완료 후 https://mdmplab.github.io/ 에서 확인합니다.

사이트 화면에 필요한 그림과 모집공고는 index.html 내부에 포함되어 있습니다. index.html 하나만 교체해도 됩니다.
publications.json은 논문 목록의 편집 참고자료이며, 홈페이지는 이 파일을 읽어오지 않습니다.
README.md는 관리자용 안내입니다. 업로드하지 않아도 됩니다.
